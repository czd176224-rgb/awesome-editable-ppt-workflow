## 保留的边界

- 保留原有六段提示词、字段、顺序和正式插件路线，不另建生成器或一套平行提示词。
- 原文的全部独立信息及限定、关系、语气保留；允许忠实重组和图文转换。保留信息结构，不等于锁定Word表格/段落的表现形式。
- 整页自由构图；局部按需图表；定性机制可以复杂表达但不伪造测量尺度。不强制每页图表、主图、结论或统一布局。
- 正文不因拥挤擅自拆页；原有目录续页、章节页、结束页功能不变。1.2.2、既有快照、封面代码和数值校验不变。
- 不增加Agent、模型阶段、自动审核轮次、生成预算、schema或依赖。继续对真实成品检查，而非凭提示词断言达标。
- 用户已拒绝完整缩小图片再补背景留白；不得采用该方案。也不采用非等比拉伸、手工补字或整页截图冒充可编辑输出。

## 已确认的原因及证据边界

1. 第14页导演主动要求四列七行表格作为唯一主体；第21页主动选择连续文本分组。仅责怪Image2没有理解不成立，首要问题是设计选择被收窄。
2. 第29页分析字段已有并列需求、共同属性、投前退出设计的判断，六段执行指令并未同等明确地表达全部判断。编译器只消费六段，这一点本身不应通过叠加第二套执行指令修复。
3. 三页六段原始内容约1100—1300字符，编译后约一万字符，含无条件注入的八类图表工具说明。长度是可精简点，不是已证实的单一故障原因。
4. 审核与生成在事实、关系和完整性上基本一致；现有严重错误门槛不能替代用户对表达质量的验收。不能只提高审核门槛使生成器反复返工。

## 最小设计

六段是唯一的生图执行设计。creative_direction继续作为导演分析记录，不再被视为一套额外的、需要Image2自行补全的设计权威。导演在同一次调用中将所有影响可见结果的关系和空间决定完整落入六段；不把全部分析记录再拼到提示词末尾。

| 原有段落 | 本次明确的职责 |
| --- | --- |
| Task and Canvas | 安排本页内容区域、主辅空间、阅读路径；区域大小结合完整文案和参考图，而非只写上中下。固定画布和固定层仍由编译器拥有。 |
| Core Proposition and Content | 提供实际要表达的完整内容，允许文字与图形共同承载；不要先抄整段再要求图形重复同一内容。共享标签仍须范围明确。 |
| Consulting Information Architecture | 明确哪些对象并列、共同指向什么、哪些是属性、条件或时序；连接线承担什么含义。不能让Image2猜原文未给出的因果或流程。 |
| Visual Style and Color | 实现已确认风格与色彩，不把克制误解为只能文字；不改变用户配色边界。 |
| Text and Typography | 完整说明、标签和来源的层级及换行，不能用极小字满足表面完整。 |
| Strict Prohibitions | 保留本页具体误读风险和必要边界，避免重复整套设计过程。 |

导演参考的图表工具箱与Image2的执行指令分工：前者帮助选择，后者执行已选设计。将八类通用选择说明保留给导演，不无条件塞给每张图片；保留生图必须知道的短事实/定量边界，不删除数值验证。

审核继续使用完整Word和实际生图提示词，不新增输入来源。检查本页主关系是否真正可见，而非检查是否用了指定复杂图表名称；表格确实最合适时仍允许。其独立事实权威不受导演方案覆盖。

## 三页验收目标，不是新增模板

- 14：七个连续环节和每一环节的三类对应信息可同时阅读；所有32个表格内容单元有表达。可以保留表格，也可以使用连续主轴结合信息带，但不能因为原文是表格就预先禁用其他形式。
- 21：进展、公开披露范围、判断限制与稳妥结论形成清楚的论述；不强求把全部长文图形化，不将两种不同口径的金额作规模对比。
- 29：职责边界、三类并列需求、拟转化的资产项目、项目共同属性、投前退出设计与公司材料各有明确归属；参考照片让位于完整内容，不挤掉职责句。投前设计不画成投资后的最后一个阶段。
