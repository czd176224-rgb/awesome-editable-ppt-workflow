# word-ppt-workflow-v5 项目目录

一页 Word 对应一页 16:9 PPT。Image2 正文图固定为 1904×896、17:8，比例相对误差门槛为 1%；标题、SVG Logo、页脚和页码不进入正文图。

- `00_source/`：锁定 Word、原始 SVG Logo、分页、批注和页内素材。
- `01_page_contracts/`：逐页标题、完整原文、表格、批注及来源绑定。
- `02_style/`：唯一一次确认的整体视觉合同及审计结果。
- `04_v5/`：项目 DAG、请求幂等账本、材料注册表、Image2 设计验收、逐页重建、同区域最终 QA 和运行报告。
- `08_final/`：按锁定顺序组装的最终 PPT、Office/OpenXML 证明与交付摘要。

页内图片默认作为 Image2 参考；只有逐页批注或确认合同明确要求时才必须出现。真实素材只在源文件没有提供且页面明确需要时搜索一次。任何硬性用户要求失败、来源损坏或过期页面都不得进入最终文件；软性 QA 建议仅记录，不阻塞交付。
