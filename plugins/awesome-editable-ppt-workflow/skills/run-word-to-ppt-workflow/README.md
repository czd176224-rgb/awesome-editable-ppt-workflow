# Paginated Word to editable PowerPoint V6

Use `run-word-to-ppt-workflow` as the sole public workflow and `run-pages` as the sole formal page-generation command. A one-page run uses `run-pages --pages 1`; there is no separate legacy single-page generation or prompt-compilation entry.

The workflow preserves complete page materials and opens one three-step confirmation UI. Step 1 confirms one whole-deck director template from five scenarios: Company & Business Introduction, Investment Committee, Project Initiation, Corporate Planning Report or Investment Project BP. Step 2 confirms only three colors, CJK/Latin fonts and title/body/caption sizes. Step 3 confirms only the seven-field presentation taskbook: use scenario, presenter, primary audience, audience prior knowledge, desired outcome, Word content to emphasize and content to keep lower prominence.

Word remains the factual and per-page content authority. The taskbook can influence emphasis, hierarchy, reading path, evidence framing and takeaway selection, but cannot add, omit, rewrite or move Word content. Page count and the existing automatic composition are not user-editable in this UI. Template metadata never enters model prompts. Material-gap discovery and user supplementation are not part of this confirmation upgrade.

The workflow then invokes the existing consulting page director before the candidate loop. The director and the fresh independent reviewer each load the confirmed taskbook separately; the reviewer does not receive the serialized director output or reuse the director thread. Each candidate receives the local technical check followed by the single independent semantic visual review, including coherent consulting argument, report-grade visual style, and confirmed semantic-color checks. Rejections alone may trigger at most two corrections. Signed accepted v1.0.1 pages remain recoverable; unfinished or explicitly regenerated v1 pages restart fresh under director v2 and never reuse legacy prompts or candidates.

Every reviewed body candidate is the final dynamic 17:8 crop uniformly resized to 1904x896. Accepted images then become the sole visual input to editable reconstruction; fixed title, SVG Logo, footer and page number remain native layers outside Image2.
